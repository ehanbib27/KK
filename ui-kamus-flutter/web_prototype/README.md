# Prototipe web asli

Folder ini mempertahankan prototipe web multi-halaman. Versi Flutter yang dikembangkan ulang berada di `../lib/` dan menggunakan data JSON dalam `../assets/data/`.

Untuk menjalankan web prototype, buka folder `web_prototype` melalui VS Code dan jalankan `index.html` dengan Live Server, karena halaman membaca data JSON menggunakan fetch.
